💻 Behind This Website

Tentang Website Ini

Halaman ini berisikan informasi mengenai tujuan pembuatan website, proses penyusunan, sumber konten, serta referensi yang digunakan dalam pembuatan website Singkong Keju Kenti.

Latar Belakang

Dibuat untuk Bahan Pembelajaran, Sekaligus Mempromosikan Usaha Keluarga.

Website Singkong Keju Kenti dibuat sebagai bagian dari pengerjaan tugas mata pelajaran Informatika tahun ajaran 25/26 di SMAN 3 Bandung. Selain untuk menerapkan materi pembuatan website, tugas ini juga menjadi kesempatan untuk membantu memperkenalkan dan mempromosikan usaha makanan milik orang tua. Melalui website ini, pengunjung dapat mengenal produk, melihat pilihan menu dan harga, serta menemukan informasi untuk melakukan pemesanan.

🎯

Tujuan Pembuatan

  • Memenuhi tugas praktik mata pelajaran Informatika.
  • Menerapkan dasar HTML, CSS, dan JavaScript dalam sebuah website.
  • Membantu mempromosikan produk Singkong Keju Kenti milik orang tua.
  • Menyediakan informasi produk, pilihan rasa, harga, dan cara pemesanan dalam satu tempat.
  • Melatih kreativitas, kemandirian, dan kemampuan merancang tampilan website yang mudah digunakan.
👥

Sasaran Pengunjung

Website ini ditujukan untuk masyarakat umum, khususnya calon pelanggan yang ingin mengetahui produk Singkong Keju Kenti.

📸

Sumber Gambar dan Konten

Foto-foto produk yang digunakan pada website merupakan dokumentasi pribadi milik orangtua saya, bukan mengambil dari website lain. Nama file gambar yang digunakan adalah:

  • singkongkeju.jpg
  • singkongbalado.jpg
  • singkongmentah.jpg
  • singkongoriginal.jpg

Informasi nama produk, harga, alamat, nomor pemesanan, dan akun Instagram diperoleh dari informasi usaha Singkong Keju Kenti milik orangtua saya.

🧭

Referensi dan Inspirasi

Konsep tampilan website terinspirasi dari pola desain website e-marketplace di aplikasi pinterest dan toko online, seperti katalog produk, navigasi menu, kartu produk, informasi harga, serta bagian pemesanan. Referensi tersebut digunakan sebagai inspirasi penyusunan tampilan, bukan untuk menyalin foto atau identitas visual milik platform lain.

ShopeeFood — referensi layanan pesan antar Kunjungi ↗
GrabFood — referensi layanan pesan makanan Kunjungi ↗
🛠️

Teknologi yang Digunakan

  • HTML untuk menyusun struktur dan isi setiap halaman.
  • CSS untuk mengatur warna, tata letak, ukuran, font, dan tampilan responsif.
  • JavaScript untuk fungsi sederhana, seperti membuka dan menutup menu navigasi pada perangkat seluler.
  • Visual Studio Code / Notepad dapat digunakan sebagai aplikasi untuk mengedit kode website.
🎨

Konsep Desain

Website menggunakan warna oranye dan kuning pastel untuk memberikan kesan hangat, ceria, ramah, menggugah selera, juga saya pilih karena warna tersebut ialah warna favorit saya. Jenis huruf dibuat rounded dengan ketebalan yang cukup agar terlihat menarik tetapi tetap nyaman dibaca. Susunan halaman dibuat konsisten supaya pengunjung mudah berpindah dari Home, Produk, Profil, Kontak, hingga halaman ini.

Catatan: Tautan GoFood, ShopeeFood, dan GrabFood pada website merupakan tautan menuju halaman layanan masing-masing. Website ini berfungsi sebagai media informasi dan promosi; pemesanan tetap dikonfirmasi melalui kontak yang tersedia atau aplikasi layanan terkait.
